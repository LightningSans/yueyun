## 本模块说明

`yueyun_fronted` 是悦选商城的后端单体核心（Spring Boot 3.3 + Maven），同时包含三个前端子模块：

| 目录 | 说明 |
|------|------|
| `src/` | Java 后端源码 |
| `yueyun_AdminUI/` | 管理后台前端（Vue 3 + Element Plus） |
| `yueyun_userUI/` | 用户前端（Vue 3） |
| `yueyun_curUniapp/` | 配送员微信小程序（UniApp） |
